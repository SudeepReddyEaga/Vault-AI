What you will build

You will build one AI agent that helps with an everyday task. Pick one topic from the list of 30 below. Every 
project has the same simple shape:

● One agent with a plan-act loop (it takes more than one step).
● At least two tools the agent calls (small Python functions are fine).
● Memory so it remembers earlier turns in the same conversation.

You may use any lane from the course (free GitHub Models or Microsoft Foundry, your choice). Marks do 
not depend on the lane.

The one rule: an agent, not a chatbot

The simplest way to think about it: a chatbot answers, an agent acts. A chatbot is a vending machine, one 
question in, one answer out. An agent is an intern, you give it a goal and it decides which tools to use, does 
several steps, remembers what it found, and comes back with a result.

Your project must show all three of these, or it does not meet the course outcomes:

● It calls tools (at least two), not just generates text.
● It takes more than one step, deciding what to do next from tool results.
● It remembers earlier turns and uses that memory later.

A project that only does "user asks, model replies" will not pass, however polished it looks.

Solo or group of three

You may work alone or in a group of up to three. Same topics for both. A solo project builds the core shape 
(two tools plus memory). A group of three also builds the Group of 3 add-on listed under the topic, so the 
workload is fair.

What to submit

Submit a single zip (or a GitHub link) containing:

● Your code (the agent and its tools).
● A short README: name the two tools, say what the memory does, and describe one honest failure 

you hit and how you handled it. Three short paragraphs, no essay.

● A notebook demo that runs the agent on 2 to 3 example goals and shows the multi-step trace (the 

tool calls and steps). This is your proof it is an agent, not a chatbot.

Group submissions: add a one-line who-did-what note in the README.
